CSS Naked Day
======================

This module simply removed the CSS from your site on April 9th so you can
participate in the CSS Naked day to promote web standards.

Get more information at https://css-naked-day.org/

Installation Instructions
-------------------------

1. Download and unpack the module in your modules directory. Install the module
as you normally would at admin/build/modules. Don't be spooked by the empty
.module file. The work happens in the .info file and the use of the
CSSNakedDay.js file.
2. Download the CSSNakedDay.js file from https://github.com/tobiassjosten/CSSNakedDay.js
3. Place the CSSNakedDay file in the same folder as the module.

Requirements
------------

This module requires that the following JavaScript library is also enabled:

 * [CSSNakedDay.js](https://github.com/tobiassjosten/CSSNakedDay.js)

Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- Copy CSSNakedDay.js into the module folder. Download it from the
  above link in the Requirements section.
